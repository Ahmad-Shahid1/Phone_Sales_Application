Phone Sales Application:

A Java console program that demonstrates object-oriented programming using phone listings, price validation, and a $50 discount for the sample Apple phone.

Features:

-Displays phone brands, operating systems, and original prices.

-Calculates and displays the discounted price for the sample Apple phone.

-Rejects negative original prices.

-Demonstrates abstraction, inheritance, and polymorphism.

Files:


-PhoneAbstract.java — defines the abstract phone class and shared details.

-PhonesForSale.java — handles phone prices, validation, and discount calculations.

-PolymorphismPhoneTest.java — contains the main method and sample phone listings.

Running the Project:

You'll need a Java Development Kit (JDK) installed and available in Command Prompt. JavaFX is not required.

Place all three Java files in the same folder and open Command Prompt there.

Compile:

javac PhoneAbstract.java

PhonesForSale.java

PolymorphismPhoneTest.java

Run:

java PolymorphismPhoneTest

The program displays the sample phones defined in the code. No input.txt file or keyboard input is required.
